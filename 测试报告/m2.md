## 5. 关键决策 / 踩坑（本阶段）

1. **AGE preload 与 TRUNCATE**：`dsh_memory` 容器 `shared_preload_libraries=age` → 任何 `TRUNCATE` 都触发 AGE 钩子、因无 `ag_catalog` schema 而失败。**单测改用 5433 无 AGE 容器**（生产仍可用 54320，连接池已 `options: '-c search_path=public'` 防 name 解析污染）。
2. **search_path**：连接池启动参数固定 `public`，避免继承库级 search_path 中的 AGE 残留 schema。
3. **CJK 检索决策（D-M2-1）**：
   - **问题**：初版用 `ILIKE '%q%'` trigram 初筛，对中文失效——`facts.content` 是三要素空格连接（`用户 偏好 简洁回复`），查询 `用户偏好`（无空格）时 0 命中。
   - **思考**：A. ILIKE + 去空格归一化（trigram 对短中文片段效果弱、SQL 表达式难维护）；B. 全表扫 + keywordScore（CJK 二元组，参考实现同构）；C. pg_trgm `similarity()` 相似度（短查询/中文不稳、阈值难调）。
   - **最终决策**：选 **B**。workspace 小规模（§3.5 几十~几百条）下无索引扫描可接受；检索正确性 > 索引微优化；trigram 索引保留作未来大库粗筛。
4. **getFactById 需排除软删除**：初版漏 `deleted_at IS NULL`，软删后仍可见 → 已修。
5. **vitest 无 config 文件**（本环境 rolldown 加载 config 崩）→ 用默认 include。

> 完整决策记录（含各备选权衡）见 `开发经验.md` D-M2-1 / D-M2-2。
